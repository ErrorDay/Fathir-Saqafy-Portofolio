Studi kasus teknis

Presensi Sekolah

Proyek yang berawal dari karya tulis ilmiah dan terpilih sebagai Best KTI saat exhibition sekolah, lalu dilanjutkan menjadi sistem presensi siswa dan pencatatan kunjungan perpustakaan.

Dari karya tulis ke kebutuhan sekolah

Setelah proyek kami terpilih sebagai Best KTI, sekolah sepakat untuk melanjutkannya agar dapat digunakan untuk presensi dan pencatatan kedatangan tamu perpustakaan. Sistem ini ditujukan untuk bagian kesiswaan, kurikulum, perpustakaan, dan guru wali kelas.

Peran saya dalam tim

Proyek ini dikerjakan oleh dua orang. Saya menangani backend dan database menggunakan Supabase, sementara rekan saya mengerjakan frontend.

Memilih pengenalan wajah

Kami ingin mencoba pendekatan selain kartu NFC atau QR code. Wajah siswa didaftarkan terlebih dahulu, diproses menjadi embedding, lalu disimpan di database. Saat presensi, sistem mendeteksi wajah dan menggunakan backend Python untuk proses pengenalan. Database dan autentikasi ditangani oleh Supabase.

Untuk memilih library, kami mengevaluasi face_recognition, deepface, dan cv2. Hasil awal belum optimal: beberapa opsi terasa berat atau lambat. Setelah riset dan percobaan, saya memilih InsightFace karena menurut evaluasi kami lebih ringan, cepat, dan akurat untuk menghasilkan embedding. Saya belum mencantumkan angka benchmark karena belum ada metrik terukur yang dibagikan.

Dari prototipe ke aplikasi live

Proyek dimulai sebagai prototipe KTI kelas 11. Setelah demo penuh pada sidang akhir, proyek memenangkan Best Project pada exhibition sekolah. Sekolah kemudian mengadopsi sistem ini; aplikasi sudah online untuk digunakan. Frontend dideploy di Vercel dan backend di Render.

Pelajaran dan langkah berikutnya

Riset teknologi sejak awal penting untuk menghindari pilihan yang tidak sesuai kebutuhan. Proses mengevaluasi library memakan waktu sekitar tiga bulan, tetapi mengajarkan saya membandingkan performa model—terutama kecepatan dan akurasi.

Langkah berikutnya yang ingin kami eksplorasi adalah liveness detection untuk membantu mencegah presensi menggunakan foto. Fitur ini belum diimplementasikan.
